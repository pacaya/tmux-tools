## MEDIUM

### M1. `prompt --format json` emits the `host` key twice (FIXED)
> **Fix:** removed `PromptJson.host`; `hosted()` is the only source; `json_of` asserts one raw `"host":` key for every verb.

Sources: C-1, X-1 (both). `src/cmd/prompt.rs:43`, `src/cmd/prompt.rs:220`, `src/cmd/mod.rs:23-28`.

`PromptJson` has its own `host` field and is then wrapped in `hosted(&output)`; `#[serde(flatten)]` does not dedupe, so stdout is `{"host":"tmux","host":"tmux",...}`. Tests parse into `serde_json::Value`, which hides the duplicate. Violates `## Contracts` "Changed JSON results" (one `host` key) and Acceptance item "For every verb that supports `--format json`, an object result has `host: \"tmux\"`".

Required outcome: every `prompt --format json` result has exactly one `host` key. Add a CLI assertion on raw stdout that detects a duplicate key (e.g. `"host":` occurs exactly once) — and apply the same raw check to the other verbs' JSON in the existing every-verb JSON test.

### M2. `prompt` refusal JSON carries no `host` / `host_state` (FIXED)
> **Fix:** refusal serialised through `hosted()` with `host_state: null`; no `submit`; refusal test asserts the keys.

Sources: C-2, X-2 (both). `src/cmd/prompt.rs:263-273`.

`report_refusal` prints `PromptRefusalJson` without `host`; `interrupt`'s refusal is wrapped. Violates Acceptance "For every verb that supports `--format json`, an object result has `host: \"tmux\"`" and P3.5, and P6.3 (`prompt --format json` reports `host_state`).

It does not carry `submit`: P6.4 defines `submit` as the observation of a submission, and a refusal submits nothing. Extend the existing refusal CLI test to assert these keys (and that `submit` is absent).

> **Fix:** `remove_pane` closes without guard read or retile when `tile` is false; split launch clears `@tt-tiled` only with `tile`; two override tests added.

Source: C-4 (lead-verified at `core/src/layout.rs:657`, `core/src/layout.rs:783-786`).
