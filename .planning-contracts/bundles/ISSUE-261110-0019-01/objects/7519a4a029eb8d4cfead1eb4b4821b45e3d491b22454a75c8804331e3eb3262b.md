### P5 — Capture, send, and keys

1. `capture` uses `hc read --lines <n>`; `--lines 0` gives the visible screen; `capture --all` uses `hc read --lines 1000000`. The History mark is the read taken before submission by one `hc read --lines 1000000`. The first changed line is the smallest line index at which the two reads differ, where a line that only one read has counts as different; when the reads are equal, it is the number of lines of the mark read. The `prompt` result is the read after settle from the first changed line to its end (empty when the read after settle has no line at that index); when the read after settle reports `how: stitched` or `how: screen`, the result is that whole read instead. This is a stated exception to PRD-261107-0825-01 P6.5 and PRD-260918-0323-01 P7 (Mark): such a result does not start at the History mark. Completeness is true only when both reads report `complete: true` and `how: history` and the first changed line is at least the number of lines of the mark read minus `rows` (from `hc get --json`); otherwise it is false (this includes `how: stitched` full-screen reads). The PRD-260918-0323-01 P4 no-scrollback notice fires when the `capture --all` read reports `how: screen`.
2. `send` keeps its PRD-261107-0825-01 P9.4 meaning. Each argument that tmux's key grammar parses as a key is sent as the matching `hc keys` key name. Literal text without Enter is sent through `hc keys`, one key per character. Every argument is checked before anything is sent: a key name with no `hc keys` name ends the verb with exit 1 and stderr `cannot type on herdr: <argument as written>`; a character outside the typeable set ends it with exit 1 and stderr `cannot type on herdr: U+<XXXX>` (uppercase hex, at least four digits). The typeable set is: space (sent as the key `space`), `a`–`z`, `A`–`Z` (sent as `shift+<lowercase letter>`), `0`–`9`, and `` ' , - . / ; = [ \ ] ` `` (sent as themselves). `hc keys` cannot type any other character, including `! " # $ % & ( ) * + : < > ? @ ^ _ { | } ~`. Nothing is sent when either check fails. When `hc keys` still rejects a key during the send, the verb exits 1 with the same message; only then can part of the input be sent. `--enter` adds the key `enter`.
3. `send-enter` sends the key `enter`; `escape` sends the key `esc`.
4. `interrupt` sends the resolved Surface's `interrupt_key` through P5.2 and keeps every current refusal rule. It never uses `hc interrupt`.
